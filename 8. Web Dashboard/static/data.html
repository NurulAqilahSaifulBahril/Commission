0 agents
Who holds which role and who they report to — this drives the override attribution. Only the Agent Name is pulled from eeAdmin, so a newly tagged agent appears here by itself; Agent Type, Role, Reports To, Branch, IC No and Nick Name are entered and kept on this page and are never changed by eeAdmin. One row per role. A promotion or transfer is a new effective-dated row, not an edit, so every role can be kept with the period it actually applied to. A new name arrives marked "⚠ Set effective date". Until you enter that month the row is not saved and no commission calculation uses it. Once dated it behaves like the rates: recalculating an old month uses the hierarchy as it stood then. An agent who leaves or is blocked in eeAdmin keeps their rows here until you delete them. Until an agent is listed here the calculation falls back to the old hardcoded name matching.

EGA Carry-Over Cases

No calculation uses this any more. These counts were entered when the May multiplier was thought to reward cases closed before the 2025 cutoff. Re-reading the printed report on 9 Sep 2026 showed it counts cases invoiced inside the 1 May – 10 June window, which the Sales Report already counts for itself, so nothing typed here reaches EP. Kept as a record of the printed figures, and as the likely home for the one rule still missing: whether an agent's campaign cases are the before-31/12/25 vintage, worth half a point per ringgit for every three cases, or the after-1/1/26 vintage, which appears to pay double.

Rows for other years are kept and saved untouched.
